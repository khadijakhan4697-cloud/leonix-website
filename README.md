# Leonix — Coming Soon Website

Official temporary landing page for Leonix.

## Deployment
The site is a standalone static `index.html` with embedded logo, Atlas illustration, favicon, responsive styles, and animations. A GitHub Actions Pages deployment workflow is in `.github/workflows/pages.yml`.

To enable publishing: **Settings → Pages → Build and deployment → Source → GitHub Actions**. Then run the workflow or push a commit to `main`.

## Contact inquiries
Buttons and form open an email draft addressed to **hello@getleonix.com**. A visitor must send the email; there is no server-side form delivery or lead database in this release. GitHub Pages does not process form submissions.

## Domain
Connect the GoDaddy domain in **Settings → Pages → Custom domain** and set the DNS records specified by GitHub. Preserve existing email records.
